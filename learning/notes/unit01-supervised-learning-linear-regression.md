| prediction y_hat | 模型预测结果。 | 不是已被实验验证的事实。 |

上述表述来自学生自述与后续自行修订；“教师补充”列不是学生原话。

## 2. 这个方法解决什么问题

当前问题：已知ZrB₂含量，估计7085Al复合材料的UTS。

单样本预测模型：

~~~text
y_hat = theta_0 + theta_1 * x
~~~

x是一个试样的ZrB₂含量，y是该试样的目标UTS，y_hat是模型估计的UTS；theta_0和theta_1是需要从数据学习的模型参数。

学生已能区分输入、目标和预测，并用给定参数计算预测。本单元不包含学习参数的算法、代价函数或梯度下降；这些主题在后续单元学习。

## 3. 当前模型的核心假设

以下为教师对学生已有理解的整理：

- 以一个特征描述输入与目标的关系，并用直线近似。
- 多个样本使用同一组模型参数。
- 训练数据的对应关系应当可信；真实材料还可能存在其他影响因素。
- 单个特征的预测关系不等于该因素的独立因果作用。

## 4. 学生已经完成的数学理解

以下模型和含量均为synthetic data；x以wt.%的数值编码，例如0.75 wt.%写作x = 0.75：

~~~text
y_hat = 500 + 40 * x
~~~

学生独立答出x = 0.75时y_hat = 530 MPa，并指出theta_0 = 500、theta_1 = 40。

学生独立答出x从0.25增加到0.85时，预测UTS增加24 MPa。

教师补充：theta_0的单位是MPa；theta_1的单位是MPa/(wt.%)。这里一个输入单位表示一个质量百分数百分点，不是含量相对增加1%。

## 5. Python理解与证据边界

学生独立写出：

~~~python
y_hat = theta_0 + theta_1 * x
~~~

函数练习最初缺少return。教师提示后学生表示不会写，随后教师提供完整函数。学生再正确判断示例调用的结果是530。

因此本单元可确认表达式理解通过，但不能声称学生已独立写出函数。详细过程见[练习档案](../exercises/unit01-supervised-learning-linear-regression.md)。

## 6. 材料科学迁移与失效条件

当ZrB₂含量与时效温度同时升高，且UTS上升时，学生判断不能将变化全部归因于ZrB₂，理由为“时效温度也是变量之一”。

教师补充：颗粒尺寸、分散性、孔隙、界面状态和热处理也可能影响UTS；遗漏相关因素、非线性关系或超出训练范围，都可能使单变量直线预测不可靠。这些是待实验验证的边界，不是本单元证实的材料强化机制。
