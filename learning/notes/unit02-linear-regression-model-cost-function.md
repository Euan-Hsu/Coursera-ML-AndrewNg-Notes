## 1. 学生已经表达的理解

| 概念 | 学生作答或最终修订摘要 | 教师补充与边界 |
|---|---|---|
| 预测函数 | 接收feature x，输出prediction y_hat；参数控制直线的位置和斜率。 | h_theta是函数，h_theta(x)是代入某个输入后得到的预测值。 |
| 截距theta_0 | 决定x为0时的大小。 | 具体指x = 0时的预测UTS，不保证等于真实基体UTS。 |
| 斜率theta_1 | x改变一个单位，y_hat的变化量。 | 本例输入单位为wt.%；斜率可正、可负、可为零。 |
| 特征与参数 | 新试样含量是输入；训练得到的theta是参数；预先选择模型形式是模型配置。 | 模型形式选择可视为超参数层面的选择，但theta_0、theta_1不是超参数。 |
| 单样本误差 | e = y_hat - y。 | 正表示高估，负表示低估；与使用相反符号定义的残差区分。 |
| 整体cost | 需要把全部训练样本的误差汇总成一个数。 | 汇总方式在本单元是平方、求和、除以2m。 |
| 平方的作用 | 正负误差不抵消，且惩罚较大误差。 | 绝对值也可防抵消；平方不是唯一选择，对离群大误差更敏感。 |
| 除以m | 求平均，避免只因样本数量增加而机械变大。 | 复制数据不会增加独立信息；不同数据分布的cost不能仅靠平均就公平比较。 |
| 参数空间 | (510,20)代表预测直线510 + 20x。 | J才是该参数点对应的高度；三组候选最低不代表全局最优。 |
| 材料边界 | x增加时模型预测UTS增加，但不能保证真实UTS增加，其他成分和热处理也可能影响。 | 正斜率是模型关系，不是独立因果效应；小训练cost也不证明新实验准确。 |

这些结论有首次正确、提示后修正和复测后通过之分，详见测验和错题档案。

## 2. 解决什么问题与核心假设

任务：用ZrB₂含量这个单一输入，预测7085Al复合材料UTS，并比较不同预测直线在同一训练数据上的拟合程度。

当前模型假定关系可由一条直线近似；全部训练样本共用一组参数；比较模型时训练数据及其单位保持不变。该假设并不保证颗粒增强材料的真实响应线性。

符号约定：

- x：单个样本的feature（输入特征）；X通常表示全部样本的特征集合。
- y：target（目标值）；真实研究中来自观测，本档案数值例子的y为模拟目标。
- y_hat：prediction（模型预测值）。
- theta_0、theta_1：模型从数据中拟合的参数。
- m：训练样本数；上标(i)为样本序号，不是乘方。

## 3. 公式与计算逻辑

$$
\hat y^{(i)}=h_\theta(x^{(i)})=\theta_0+\theta_1x^{(i)}
$$

$$
e^{(i)}=\hat y^{(i)}-y^{(i)}
$$

$$
J(\theta_0,\theta_1)=\frac{1}{2m}\sum_{i=1}^{m}
\left(\theta_0+\theta_1x^{(i)}-y^{(i)}\right)^2
$$

loss可表示单个样本的损失，例如误差平方；本单元cost J是整个训练集的平均平方误差的一半。具体教材命名可能不同，应看公式及汇总范围。

计算步骤：预测 → 逐项相减 → 逐项平方 → 求和 → 除以2m。

x以wt.%的数值编码，例如0.5 wt.%写作x = 0.5。y和y_hat单位为MPa，theta_0单位为MPa，theta_1单位为MPa/(wt.%)，J单位为MPa²。

教师补充：除以m得到平均；再除以2主要为了后续求导简便。乘以固定正数不改变最优参数的位置；是否除以2不改变同一数据集内的模型排序。这里不展开参数更新算法。

## 4. 手算与图像理解

学生独立算出，h(x) = 490 + 50x、x = 0.6、y = 515时：

~~~text
y_hat = 520 MPa
e = 5 MPa
e² = 25 MPa²
~~~

代价函数独立复测：误差为[-4, 2, 6]，学生答平方和56、2m = 6、J约9.3；精确值为28/3，保留两位小数为9.33。

数据图中横轴为x，纵轴为UTS；一组参数对应一条直线，竖直差距反映误差。参数图中坐标是theta_0、theta_1，J表示高度。学生曾将参数点与高度混淆，后自行写出对应直线。

教师补充：普通最小二乘代价是凸二次函数；输入x存在变化时，两参数通常有唯一最小点。若所有x相同，可能出现多组参数同样最优，不能无条件声称只有唯一“碗底”。

最小化J表示在指定模型形式与训练数据下寻找平方误差最小的参数，不等于找到了对所有新材料最优的模型。

## 5. Python实现与验证边界

教学代码把预测和cost分别写成函数，使用NumPy数组批量计算：

~~~text
y_hat = theta_0 + theta_1 * x
errors = y_hat - y
squared_errors = errors ** 2
cost = squared_errors.sum() / (2 * len(x))
~~~

学生能手算三个预测值、误差数组、平方数组和cost；闭卷能说明函数最终返回整体cost。

本单元完整函数由教师提供，没有学生独立编写完整函数或真实运行日志。应评价为能读懂函数和数组运算，不能据此认定已独立实现并运行通过。

## 6. 材料迁移与失效条件

学生最终修订：给定正斜率模型，增加x会增加模型预测值y_hat；不能证明实际UTS必然增加，因为其他成分和热处理也可能影响。

教师补充：遗漏的时效条件与颗粒含量一起变化时，单变量模型无法分离二者作用。颗粒尺寸、团聚、孔隙和界面状态也可能影响关系。训练范围0—1 wt.%不能直接支持3 wt.%的可靠预测。平方误差对极端观测敏感，数据录入与实验测量质量也需要检查。
