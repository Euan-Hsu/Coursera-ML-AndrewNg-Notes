## 1. 解决什么问题：把多个材料样本组织起来

一个 sample（样本）有多个 feature（输入特征），模型根据这些输入预测一个 target（目标），本单元目标只有 UTS。

学生已在作答中说明：样本编号不决定向量的长度；输入特征很多，不意味着输出必须有很多列。矩阵按行存放样本，按列存放输入项；原始矩阵不含人为常数列。

## 2. 符号对应什么材料信息

材料特征顺序固定：

| 特征编号 j | 材料变量 |
|---|---|
| 1 | Zn含量 |
| 2 | Mg含量 |
| 3 | Cu含量 |
| 4 | ZrB2含量 |
| 5 | 时效温度 |
| 6 | 时效时间 |

- \(m\)：样本数。
- \(n\)：实际选用的材料特征数，不包括人为加入的常数。
- \(x^{(i)}\)：第 \(i\) 个样本的全部原始特征，按数学列向量约定，shape为 \((n,1)\)。
- \(x_j^{(i)}\)：第 \(i\) 个样本的第 \(j\) 个特征值，是标量。
- 上标 \((i)\) 是样本编号，不是乘方，也不是行数。

例如，\(x_5^{(12)}\) 是第12个样本的时效温度。即使样本编号换成12，六特征向量的shape仍是 \((6,1)\)。这些编号只是结构示例，不声称存在这批实验数据。

## 3. 参数、截距与单样本模型

\(\theta\) 是 parameter vector（参数向量），不是材料数据。模型含截距 \(\theta_0\) 和 \(n\) 个特征参数：

\[
h_\theta(x)=\theta_0+\theta_1x_1+\cdots+\theta_nx_n
\]

引入人为常数 \(x_0=1\)，得到增广特征列向量：

\[
\tilde x=
\begin{bmatrix}
1\\
x_1\\
\vdots\\
x_n
\end{bmatrix},
\qquad
\theta=
\begin{bmatrix}
\theta_0\\
\theta_1\\
\vdots\\
\theta_n
\end{bmatrix}
\]

于是同一个加法式可以写成：

\[
h_\theta(x)=\theta^\mathsf{T}\tilde x
\]

\(\tilde x\) 和 \(\theta\) 都是 \((n+1,1)\)，转置后的 \(\theta^\mathsf{T}\) 是 \((1,n+1)\)。对应项相乘再相加，得到一个样本的预测数值。若用二维数组计算，乘积shape为 \((1,1)\)。

学生已说明：参数数量取决于特征数以及是否含截距，与样本数无关；同一个模型对不同样本使用同一组参数。

## 4. 从单个样本到所有样本

数学记号用 \(X_{\mathrm{raw}}\) 表示原始矩阵、\(\tilde X\) 表示增广矩阵；本单元Python代码中的 `X` 指增广矩阵。

| 对象 | 含义 | shape |
|---|---|---|
| \(X_{\mathrm{raw}}\) | 所有样本的原始特征 | \((m,n)\) |
| \(\tilde X\) | 最左侧增加常数列1 | \((m,n+1)\) |
| \(\theta\) | 含截距的参数列向量 | \((n+1,1)\) |
| \(y\) | 目标UTS | \((m,1)\) |
| \(\hat y\) | 预测UTS | \((m,1)\) |

原始矩阵的第 \(i\) 行是 \((x^{(i)})^\mathsf{T}\)，不是数学列向量 \(x^{(i)}\) 本身。

\[
\hat y=\tilde X\theta,\qquad
(m,n+1)@(n+1,1)\longrightarrow(m,1)
\]

学生对计算机制的补答是：每行与参数对应相乘，再相加；各样本共享同一个theta。因此每行得到一个预测值，而不是每个特征得到一个预测值。

内侧维度相等只能证明乘法合法。若模型要求截距却漏了截距项，即便能够相乘，也没有正确表达要求的模型。

`y` 与 `y_hat` 的同一行必须对应同一个样本。shape相同不意味着数值相同；`y` 的角色是目标值，`y_hat` 的角色是预测值。在教学例题中，`y` 也可以由synthetic data提供，不能因此称为实验测量。

## 5. NumPy实现：数学方向不等于数组维度

学生独立写出的参数构造与预测语句如下；参数是 **synthetic data（模拟数据）**，不是实验拟合结果：

```python
theta = np.array([[20], [2], [-1]])
y_hat = X @ theta
```

`np.array` 把给定列表构造成数组；嵌套列表的层次决定这里的一维/二维结构；`shape` 是各轴长度；`@` 是矩阵乘法。

对于本单元的二维增广数组：

```python
X[i, :]   # 第i+1个样本；返回shape为(n+1,)
X[:, j]   # 列索引j的数据；返回shape为(m,)
```

一个整数索引固定并去掉一个轴，冒号保留另一个轴。数据来自一行或一列，不代表返回值还保留二维行列方向。`(7,)` 不等于 `(7,1)` 或 `(1,7)`。

数学特征编号从1开始，NumPy索引从0开始。对于 \(j=1,\ldots,n\)，对应关系为：

\[
x_j^{(i)}=X_{\mathrm{raw}}[i-1,j-1]=X[i-1,j]
\]

上式中的 `X` 已有常数列。因而列索引5对应时效温度，索引6才对应时效时间。

## 6. 表示与预测流程（教师归纳，非新增独立测试）

1. 确定样本、特征、目标，以及固定的列顺序与单位。
2. 数出 \(m,n\)，组成原始矩阵 \((m,n)\)。
3. 需要截距时，在左侧加入常数列，组成 \((m,n+1)\)。
4. 按相同输入顺序构造参数列数组 \((n+1,1)\)。
5. 先检查内侧维度，再计算 `X @ theta`。
6. 确认输出 \((m,1)\)；若与目标比较，保证样本逐行对齐。

这里只使用已经给定的参数，不包含如何学习这些参数。

## 7. 材料迁移、核心假设与何时失效

学生最终在11样本、6特征的结构题中，正确给出原始矩阵 \((11,6)\)、增广矩阵 \((11,7)\)、参数 \((7,1)\)、目标及预测 \((11,1)\)。`X[:, 4]` 是所有样本的ZrB2含量，shape为 `(11,)`；`X[8, 5]` 是第9个样本的时效温度，属于标量。该题是synthetic data的结构设定，不是实验结果。

以下为教师补充的适用边界，并未另外作为独立闭卷题检验：

- 同一模型采用固定的输入顺序、数据含义和单位，所有样本共享参数。
- 线性模型假设目标可以用输入的加权和加截距近似；这是需要数据验证的建模假设，不是已证明的材料规律。
- 列顺序、单位或目标行顺序错位时，即使shape正确，计算含义也会出错。
- 真实材料关系若存在明显非线性或交互作用，此表示可能不足。计算合法不等于预测准确，参数也不能直接解释为材料因果机制。
