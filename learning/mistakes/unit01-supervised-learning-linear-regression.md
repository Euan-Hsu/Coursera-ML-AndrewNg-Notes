# 单元01：监督学习与单变量线性回归基础——错题与易混淆点

归档日期：2026-10-16。证据来源：本聊天。所有假设材料数值均为synthetic data。

本档案区分明确概念错误、可能笔误与单次算错。不能将所有条目都称为“反复未掌握”，也不能由本单元推断后续单元的当前能力。

## 1. target y与prediction y_hat

### 错误现象与当时理解

题目给出模型预测540 MPa、实测532 MPa，学生回答“540 MPa是target y，因为它是模型预测的结果”。这是明确的概念混淆。

随后一轮输入/预测/目标辨认中，学生把第三项写为“第一个是y”；前两项正确，后又正确完整重述。此处只能记为疑似笔误或表述错误，不能确认是同一概念再次误解。

### 正确解释与发现过程

教师根据数值来源指出：当前材料案例中，y是观测UTS，y_hat是模型预测。模型输出不自动成为实验目标值。

### 更正与最新验证

学生随后正确辨认548为y_hat、551.2为y；又正确重述X = 0.7 wt.% ZrB₂、y_hat = 536 MPa、y = 529 MPa。最终自述也正确区分。

本单元结论：已纠正。没有据此认定持续未掌握。

### 自检方法

先问数值来自实验测量还是模型计算，再写符号；模拟题中的y是模拟目标，不能称为真实实验结果。

## 2. 线性模型代入时的单次计算错误

### 错误现象与原理解边界

对y_hat = 510 + 25 * x、x = 0.6，学生首次回答535，并正确说明斜率的基本含义。没有充分证据确定算错的具体原因。

### 发现与纠正

教师提示先算25 * 0.6再加510；学生更正为525。后续两道数学测验分别独立答出530与24，均正确。

### 自检方法与状态

分步写出乘法项，最后相加，并注明MPa。状态：单次错误已纠正，不标成反复计算障碍。

## 3. Python函数缺少return

### 错误现象与当时理解

学生在函数体中用函数同名局部变量保存表达式，没有return。原答显示了“计算一个值”，没有把结果返回给调用者；不能据此推断更多心理原因。

### 正确解释

Python赋值保存局部值，return将结果交给调用方。没有显式返回时函数默认返回None。同名局部赋值并非语法错误，但不利于初学者阅读。

### 发现与验证

教师先指出原因和提示；学生表示不会后，教师提供完整函数。学生能算对随后调用的数值结果。

### 自检方法与状态

检查函数的输入、缩进、是否执行return，以及调用方接收什么。单元01结束时仍需独立编写练习；不将教师代码记为学生首次独立实现。后续能力变化以最新进度为准。

## 4. 其他表述修订

- “监督学习需要输入输出的参数”：修正为输入数据与对应的已知目标；模型参数theta与数据不同。
- “训练样本是完整数据的一行”：经提示后学生改为用于训练的输入和真实目标配对；数据存在缺失时仍可能是一条样本。
- “斜率表示输出增加”：学生改为预测UTS的变化；教师补充负斜率也可能出现，需说明含量单位。
- MP应写作MPa；逗号小数等为展示/书写修订，不擅自推断为数学概念错误。
- ini代码围栏属于显示标签，不影响表达式本身的正确性。
