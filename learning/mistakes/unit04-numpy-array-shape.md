## 本次回答中的错误

题目中的数组是：

```python
p = np.array([100, 40, 20])
q = np.array([[100, 40, 20]])
r = np.array([[100], [40], [20]])
```

学生正确判断 p.shape 为 (3,)，但将 q.shape 写为 (1, 2)，将 r.shape 写为 (2, 1)，并选择 q 作为要求 shape 为 (3, 1) 的参数向量，理由是“内侧数一样”。

## 正确理解

- p 是长度为3的一维数组，shape 为 (3,)，没有显式行列方向。
- q 是二维数组，1行3列，shape 为 (1, 3)。
- r 是二维数组，3行1列，shape 为 (3, 1)。
- 本单元约定 theta 使用二维列数组，因此 r 符合要求。
- 对规则的二维嵌套列表，外层列表中的每个内层列表表示一行，内层列表的元素数表示该行的列数。
- 判断数组自身的 shape 要数行列；“内侧维度相同”用于检查两个数组的矩阵乘法是否合法。
- NumPy 也允许使用 shape 为 (3,) 的一维参数数组；那是另一种表示约定，不是本题要求的二维列数组。

## 需要继续验证

不能仅由本次答案断定错误原因。接下来要求学生直接数 q、r 的行数和列数，并说明选择二维参数列数组的理由。

## 自检方法

1. 判断是一维列表还是二维嵌套列表。
2. 对二维数组先数行，再数每行元素。
3. 检查行数乘列数是否等于元素总数。
4. 选择 theta 前，先确认题目约定的参数 shape。

## 2026-10-11：整数索引取整行与整列后的 shape

前述 q、r 的数组构造题已在提示后答对，并能构造 shape 为 (3, 3) 的增广 X 和 shape 为 (3, 1) 的 theta。

本轮数组仍为 synthetic data，仅用于教学：

```python
X = np.array([[1, 7, 2], [1, 8, 1], [1, 6, 3]])
```

列索引0为常数1，列索引1为Zn含量，列索引2为Mg含量。

### 本轮回答

- 正确指出 X[2, :] 对应第3个样本，值为 [1, 6, 3]，但将 shape 写成 (1, 3)。
- 将 X[:, 2] 的材料含义写为Zn；对应的数值取对，但按二维列数组书写，并将 shape 写成 (3, 1)。
- 能正确说明 shape 为 (3,) 的一维数组不能称为3行1列。

### 正确理解

对于本轮二维数组，整数索引固定一行或一列时，会去掉该维度：

- X[2, :] 返回一维数组 [1, 6, 3]，shape 为 (3,)。
- X[:, 2] 返回全部样本的Mg含量，一维数组为 [2, 1, 3]，shape 为 (3,)。
- 数据来自数学上的一行或一列，不意味着NumPy返回值仍保留二维行列形状。
- 常数列占列索引0，因此列索引1与2分别对应Zn与Mg。

### 下一次检查

改用4行3列的增广数组，分别取一行和一列，要求先报告元素数量，再报告NumPy shape，检验能否将一维规则用于不同长度的结果。暂不引入保留维度切片或 reshape。

### 本次闭卷回答

题目为6行4列二维增广数组 A，列依次为常数1、Zn、Mg、Cu；数值均为 synthetic data，只用于数组练习，不代表实验结果。

- 正确给出 A.shape = (6, 4)、m = 6、材料特征数 n = 3。
- 正确指出 A[4, :] 是第5个样本，数值为 [1, 6, 11, 8]，但 shape 写为 (1, 4)。
- 正确指出 A[:, 2] 是Mg列，取值对应7至12，但将返回值按列方向书写，shape 写为 (6, 1)。

### 正确规则与尚未掌握的边界

对于二维 NumPy 数组，本题使用的单个整数索引会去掉该轴，冒号保留另一个轴。因此 A[4, :] 和 A[:, 2] 都返回一维数组，分别为 [1, 6, 11, 8]、shape (4,) 与 [7, 8, 9, 10, 11, 12]、shape (6,)。

数学上从矩阵取出的一行或一列，与 NumPy 返回数组保留了几个轴是两个不同问题。返回数据在原矩阵中的行列来源不能替代 NumPy 维度判断。

### 错误现象

一是q、r的嵌套数组行列计数错误；二是整数取行、取列后反复写成二维shape；三是增广矩阵中的Mg、时效温度等材料列名对应错误。

### 当时错误理解

依据作答能确认：数组自身shape、数学行列方向与NumPy返回维度被混用，列名与当前列索引也没有始终一致。未直接陈述的心理原因不作断言。

### 正确解释

先按数组实际轴数判断shape。对于本单元二维数组的整数加冒号索引，一个整数固定并去掉一个轴，返回一维；增广列0是常数，实际材料特征依次从列1开始。详见[错题总档第5—7项](unit04-multifeature-vectors-linear-regression.md)。
