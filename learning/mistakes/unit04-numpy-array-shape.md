## 本次回答中的错误

题目中的数组是：

```python
p = np.array([100, 40, 20])
q = np.array([[100, 40, 20]])
r = np.array([[100], [40], [20]])
```

学生正确判断 p.shape 为 (3,)，但将 q.shape 写为 (1, 2)，将 r.shape 写为 (2, 1)，并选择 q 作为要求 shape 为 (3, 1) 的参数向量，理由是“内侧数一样”。

## 正确理解

- p 是长度为3的一维数组，shape 为 (3,)，没有显式行列方向。
- q 是二维数组，1行3列，shape 为 (1, 3)。
- r 是二维数组，3行1列，shape 为 (3, 1)。
- 本单元约定 theta 使用二维列数组，因此 r 符合要求。
- 对规则的二维嵌套列表，外层列表中的每个内层列表表示一行，内层列表的元素数表示该行的列数。
- 判断数组自身的 shape 要数行列；“内侧维度相同”用于检查两个数组的矩阵乘法是否合法。
- NumPy 也允许使用 shape 为 (3,) 的一维参数数组；那是另一种表示约定，不是本题要求的二维列数组。

## 需要继续验证

## 自检方法

1. 判断是一维列表还是二维嵌套列表。
2. 对二维数组先数行，再数每行元素。
3. 检查行数乘列数是否等于元素总数。
4. 选择 theta 前，先确认题目约定的参数 shape。

## 2026-10-11：整数索引取整行与整列后的 shape

前述 q、r 的数组构造题已在提示后答对，并能构造 shape 为 (3, 3) 的增广 X 和 shape 为 (3, 1) 的 theta。

本轮数组仍为 synthetic data，仅用于教学：

```python
X = np.array([[1, 7, 2], [1, 8, 1], [1, 6, 3]])
```

列索引0为常数1，列索引1为Zn含量，列索引2为Mg含量。

### 本轮回答

- 正确指出 X[2, :] 对应第3个样本，值为 [1, 6, 3]，但将 shape 写成 (1, 3)。
- 将 X[:, 2] 的材料含义写为Zn；对应的数值取对，但按二维列数组书写，并将 shape 写成 (3, 1)。
- 能正确说明 shape 为 (3,) 的一维数组不能称为3行1列。

### 正确理解

对于本轮二维数组，整数索引固定一行或一列时，会去掉该维度：

- X[2, :] 返回一维数组 [1, 6, 3]，shape 为 (3,)。
- X[:, 2] 返回全部样本的Mg含量，一维数组为 [2, 1, 3]，shape 为 (3,)。
- 数据来自数学上的一行或一列，不意味着NumPy返回值仍保留二维行列形状。
- 常数列占列索引0，因此列索引1与2分别对应Zn与Mg。
