# Unit 04：NumPy 数组 shape 与参数列向量

记录日期：2026-10-11

## 本次回答中的错误

题目中的数组是：

```python
p = np.array([100, 40, 20])
q = np.array([[100, 40, 20]])
r = np.array([[100], [40], [20]])
```

学生正确判断 p.shape 为 (3,)，但将 q.shape 写为 (1, 2)，将 r.shape 写为 (2, 1)，并选择 q 作为要求 shape 为 (3, 1) 的参数向量，理由是“内侧数一样”。

## 正确理解

- p 是长度为3的一维数组，shape 为 (3,)，没有显式行列方向。
- q 是二维数组，1行3列，shape 为 (1, 3)。
- r 是二维数组，3行1列，shape 为 (3, 1)。
- 本单元约定 theta 使用二维列数组，因此 r 符合要求。
- 对规则的二维嵌套列表，外层列表中的每个内层列表表示一行，内层列表的元素数表示该行的列数。
- 判断数组自身的 shape 要数行列；“内侧维度相同”用于检查两个数组的矩阵乘法是否合法。
- NumPy 也允许使用 shape 为 (3,) 的一维参数数组；那是另一种表示约定，不是本题要求的二维列数组。

## 需要继续验证

不能仅由本次答案断定错误原因。接下来要求学生直接数 q、r 的行数和列数，并说明选择二维参数列数组的理由。

## 自检方法

1. 判断是一维列表还是二维嵌套列表。
2. 对二维数组先数行，再数每行元素。
3. 检查行数乘列数是否等于元素总数。
4. 选择 theta 前，先确认题目约定的参数 shape。
