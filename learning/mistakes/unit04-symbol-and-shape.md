# Unit 04 Mistake: Sample Index vs. Vector Shape

记录日期：2026-10-10

## 错误现象

将第7个样本的特征向量 (x^{(7)}) 判断为：

[
operatorname{shape}(x^{(7)})=(7,7)
]

同时能够说出 (x_3^{(7)}) 是“第7个样本的第3个特征”，但没有将其映射到当前案例中的具体变量 Cu含量。

## 错误原因

混淆了以下两个概念：

- 上标 ((i))：样本编号，只用于选择第几个样本。
- (n)：特征数量，决定单个样本特征向量中有多少个元素。

样本编号不会决定向量的维度。

## 正确理解

[
x^{(i)}=
egin{bmatrix}
x_1^{(i)}\\
x_2^{(i)}\\
dots\\
x_n^{(i)}
end{bmatrix}
]

因此，按数学列向量约定：

[
operatorname{shape}(x^{(i)})=(n,1)
]

本单元 (n=6)，所以无论选择 (x^{(1)})、(x^{(7)}) 还是 (x^{(20)})，其 shape 都是 ((6,1))。

在当前特征顺序中：

[
x_3^{(7)}
]

表示第7个样本的 Cu含量，是一个标量。

## 防止再次发生的检查方法

1. 先看括号上标 ((i))，回答“第几个样本”。
2. 再数该样本使用的特征数量 (n)。
3. 不用样本编号推断 shape。
4. 检查元素总数：((7,7)) 含49个元素，与只有6个特征矛盾。
