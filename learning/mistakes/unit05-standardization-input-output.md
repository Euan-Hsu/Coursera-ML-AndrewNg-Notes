# Unit 05：标准化代码的输入变量与结果变量

记录日期：2026-10-12。

## 练习背景

数据为 synthetic data，仅用于教学，不是实验结果。原始输入矩阵为 `X_raw`，shape 为 `(3, 6)`，六列依次为 Zn、Mg、Cu、ZrB₂含量、时效温度和时效时间。

学生已在提示后正确写出：

```python
mu = np.mean(X_raw, axis=0)
sigma = np.std(X_raw, axis=0)
```

`mu` 和 `sigma` 的 shape 均为 `(6,)`。上述评价依据对话中的代码作答，不声称代码已经实际运行。

## 重复错误的证据

第一次标准化作答：

```python
X_scaled = (x - mu) / sigma
```

同时将结果 shape 判断为 `(6,)`。

教师提示：本题没有定义 Python 变量 `x`，全部原始输入保存在 `X_raw`；广播不会删除样本维度。

第二次作答：

```python
X_scaled = (X_scaled - mu) / sigma
```

第二次未重新提供 shape。两次均未正确使用本题的原始输入变量；第二次使用了准备生成的结果变量作为输入。

## 正确解释

- 数学公式中的 x 不能未经定义直接当作 Python 变量名。
- 本题右侧需要读取原始输入 `X_raw`。
- 右侧表达式先计算，随后其结果保存到左侧的 `X_scaled`。
- 若右侧的 `X_scaled` 尚未定义，就无法完成此次计算；若此前已有该变量，则该表达式仍不是本题要求的从原始数据开始的标准化步骤。
- 每一列减去自己的均值、除以自己的标准差。广播后仍保留三个样本、六个特征，结果 shape 为 `(3, 6)`。

标准表达式：

```python
X_scaled = (X_raw - mu) / sigma
```

## 自检方法

1. 列出当前已经定义的变量。
2. 区分原始输入、统计量与待生成结果。
3. 先读等号右侧，再看结果保存到哪里。
4. 检查处理前后是否仍保留所有样本和特征。

这些是对话代码作答，不是实际运行记录，也不是换新变量后的独立迁移复测。

### 检查阶段的重复错误

任务是打印标准化后每列的均值和标准差。第一次仍写出 `print(mu) print(sigma)`：检查的是原始输入的统计量，且两条语句未分行。

教师解释：mu、sigma来自X_raw，不会在生成X_scaled后自动变为新数组的统计量；给出需要重新调用np.mean和np.std的填空框架，并明确检查对象是X_scaled。

学生再次作答：

```python
print(np.mean(X_raw, axis=0))
print(np.std(X_raw, axis=0))
```

这次两行Python语法正确，但仍然检查原始数据，而非标准化结果。问题是检查对象的选择，不是np.mean或np.std函数本身错误。

### 正确解释与后续复查

- mu、sigma是用于转换数据的原始统计量。
- 要验证标准化结果，需重新对X_scaled计算每列均值和标准差。
- `X_scaled = (X_raw - mu) / sigma` 生成新数组，并不修改X_raw。
- 在本题采用非零列标准差、且np.std默认除以m的前提下，X_scaled各列的均值应接近0，标准差应接近1。浮点计算可能存在舍入误差。
- 继续检查学生能否解释标准化完成后，原始温度列的均值仍为150°C，而标准化温度列的均值接近0。
- 后续仍需用新的数组变量进行无提示迁移复测，不把教师提供的检查代码记为首次独立写出。

## 2026-10-13：换变量名复测的进展与轴选择错误

本节更新上面的验证状态，旧段落保留其历史结论。

### 提示后的检查对象辨认

在教师给出正确检查代码并解释原始数组保留不变后，学生对“检查标准化后均值接近0应检查哪个数组”回答为X_scaled。此为提示后的概念辨认，不记为首次独立编程通过。

### 无填空框架的迁移题

题目给定 synthetic data 的原始矩阵P_raw，shape为(4, 6)；p_mean、p_std已由P_raw按列计算，shape均为(6,)，p_std各项不为0。任务为生成P_scaled并打印标准化后每列均值与标准差。

学生完整作答：

```python
P_scaled = (P_raw - p_mean) / p_std
print(np.mean(P_scaled, axis=1))
print(np.std(P_scaled, axis=1))
```

### 分项判断

- 标准化表达式正确：原始输入、原始统计量和待生成结果的角色在换变量名后选对。
- 检查对象正确：两行检查均使用P_scaled，没有再使用P_raw。
- 轴选择错误：axis=1汇总六个特征，产生四个样本各自的均值或标准差；任务要求六个特征各自的统计量。
- 先前X_raw求列均值练习中，学生也曾选择axis=1，后在提示下改正；本次独立迁移再次出现同类错误。不能据此认定轴方向已稳定掌握。

### 复习重点与下一次验证

axis指定被汇总掉的维度。对(4, 6)且行是样本、列是特征的数组：

- 按样本维度汇总，会保留六个特征各自的统计量。
- 按特征维度汇总，会保留四个样本各自的统计量。

先让学生明确需要保留的输出元素数和需要汇总的维度，再修改检查代码并换尺寸复测。
