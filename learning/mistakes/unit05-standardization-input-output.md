## 练习背景

数据为 synthetic data，仅用于教学，不是实验结果。原始输入矩阵为 `X_raw`，shape 为 `(3, 6)`，六列依次为 Zn、Mg、Cu、ZrB₂含量、时效温度和时效时间。

学生已在提示后正确写出：

```python

```

`mu` 和 `sigma` 的 shape 均为 `(6,)`。上述评价依据对话中的代码作答，不声称代码已经实际运行。

## 重复错误的证据

第一次标准化作答：

```python
X_scaled = (x - mu) / sigma
```

同时将结果 shape 判断为 `(6,)`。

教师提示：本题没有定义 Python 变量 `x`，全部原始输入保存在 `X_raw`；广播不会删除样本维度。

第二次作答：

```python
X_scaled = (X_scaled - mu) / sigma
```

第二次未重新提供 shape。两次均未正确使用本题的原始输入变量；第二次使用了准备生成的结果变量作为输入。

## 正确解释

- 数学公式中的 x 不能未经定义直接当作 Python 变量名。
- 本题右侧需要读取原始输入 `X_raw`。
- 右侧表达式先计算，随后其结果保存到左侧的 `X_scaled`。
- 若右侧的 `X_scaled` 尚未定义，就无法完成此次计算；若此前已有该变量，则该表达式仍不是本题要求的从原始数据开始的标准化步骤。
- 每一列减去自己的均值、除以自己的标准差。广播后仍保留三个样本、六个特征，结果 shape 为 `(3, 6)`。

标准表达式：

```python
X_scaled = (X_raw - mu) / sigma
```

4. 检查处理前后是否仍保留所有样本和特征。

- 标准化表达式正确：原始输入、原始统计量和待生成结果的角色在换变量名后选对。

### 复习重点与下一次验证

axis指定被汇总掉的维度。对(4, 6)且行是样本、列是特征的数组：

- 按样本维度汇总，会保留六个特征各自的统计量。
- 按特征维度汇总，会保留四个样本各自的统计量。

先让学生明确需要保留的输出元素数和需要汇总的维度，再修改检查代码并换尺寸复测。
