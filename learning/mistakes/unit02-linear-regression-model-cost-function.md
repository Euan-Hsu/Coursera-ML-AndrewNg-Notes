# 单元02：单变量线性回归模型与代价函数——错题与易混淆点

归档日期：2026-10-16。依据本聊天单元02实际作答；所有材料数值均为 synthetic data（模拟数据）。

以下区分重复概念混淆、单次计算错误和未完整回答。原因只记录有证据的理解，不推断学生未表达的心理过程。状态指单元02结束时，后续能力变化以最新progress.md为准。

## 1. 正斜率、预测值与因果关系的混淆

### 错误现象与当时理解

闭卷情境：高ZrB₂含量样本同时采用更高时效温度，模型y_hat = 505 + 35x，训练范围0—1 wt.%。

学生回答能证明含量增加导致UTS提高，理由：“能，因为theta_1为正”。

纠正后新情境为y_hat = 510 + 30x，高含量样本时效时间也更长。学生又答“不能得到ZrB₂含量增加，UTS_hat一定增加，因为还受合金元素含量和热处理影响”。

前者把模型正斜率当成因果证据；后者把真实材料的不确定性错误套到已固定的预测公式上。属于本单元反复出现的相关问题，但具体错误方向不同。

### 正确解释

固定模型theta_1 > 0时，x增加必然使该公式的预测值y_hat增加。不能因此证明真实UTS y增加，更不能证明变化由ZrB₂独立造成。共同变化的时效制度可能形成混杂。

### 如何发现与纠正

教师分别追问模型预测与真实材料行为。学生最终更正为：“能得到ZrB₂含量增加，UTS_hat增加；不能得到ZrB₂含量增加，UTS一定增加，因为还受合金元素含量和热处理影响”。

### 检查方法与验证状态

先确定句子讨论的是公式输出y_hat还是实际目标y，再判断是否含有“导致、必然、强化机制”等因果表述。

状态：修正后通过。最后纠正之后没有再进行一轮新的无提示因果题；不记作完全独立复测全对或长期掌握证明。

## 2. cost计算漏步或算错

### 错误现象与当时理解

误差[-3, 1, 5]，学生写对J = sum(e²)/(2m)，但数值答7/3。没有证据确定是平方、加法还是除法出错。

更早的单样本误差520 - 528，学生先答-6，提示后更正-8；同样不推断具体算错原因。

### 正确解释

每个误差先平方，得到非负数；再求和，最后除以2m。J的量纲为目标单位的平方，本例是MPa²。

### 如何发现与纠正

教师要求逐项计算(-3)²、1²、5²和2m，学生更正为35/6。新题[-4, 2, 6]中学生独立答出平方和56、2m = 6、J约9.3。

### 检查方法与验证状态

固定写出“平方数组 → 平方和 → 样本数m → 分母2m → J”，检查J非负，避免直接对有符号误差求和。

状态：独立新题复测通过；一位小数9.3是合理近似，不标成算错。

## 3. 参数坐标与cost高度

### 错误现象与当时理解

候选模型A：(500,40)，J = 25；B：(510,20)，J = 9；C：(520,0)，J = 30。

学生正确选择B，但将参数点(510,20)解释为“三个点中最低的点”，未说明它所代表的模型。

### 正确解释

(510,20)是两参数坐标，代表h(x) = 510 + 20x；三维代价图相应点是(510,20,9)。B只是在三组候选中cost最低，不证明全局最优。

### 如何发现与纠正

教师提示代入theta_0、theta_1；学生自行写出510 + 20x。

### 检查方法与验证状态

先读清坐标轴：数据空间是x与UTS，参数空间是theta_0与theta_1，J才是高度。

状态：提示后更正，无后续独立图像复测。

## 4. 随样本变化的量遗漏

### 错误现象与当时理解

闭卷中学生写出y_hat和e随样本变化，theta_0和theta_1共用，但遗漏x和y。原题要求辨认x、y、y_hat与两个参数。

### 正确解释

x^(i)、y^(i)、y_hat^(i)、e^(i)都按样本索引；不同样本数值可以相同。“随样本变化”不等于每行一定不同。固定模型参数在同一轮预测中共用。

### 如何发现与检查

教师根据题目所列对象指出遗漏。检查时把一行样本的信息和整个模型共用的参数分别列出。

状态：教师纠正，未在本单元独立复测该项。theta_o与theta_0也经提醒，应使用数字0。

## 5. 数组含义与数组数值未区分

### 错误现象

要求列出errors和squared_errors数组，学生只答“每个样本误差”“每个误差平方”，同时cost = 1.5正确。闭卷解释数组目的时，只答“数组能进行数学运算”。

### 正确解释与发现

解释运算含义不能代替列出逐项数值。数组用于保存多个配对样本，计算应按相同索引对应。

教师给逐项相减框架后，学生补出[-2, 2, -1]与[4, 4, 1]，正确。

### 检查方法与状态

明确题目要“说明含义”还是“写出数值”；数组题逐项对齐，再检查长度。状态：数值补答正确；完整函数独立编写与运行尚无证据。

## 6. 训练拟合与新实验预测

学生最终表述“说明对当前数据拟合较好”正确。早期表述“模型对当前模型预测能力较好”不够明确，后经提示限定为当前训练数据。

自检：比较J需同一数据集、同一目标单位和同一cost定义；训练J小不代表测试误差小，也不等于验证材料机制。3 wt.%超出0—1 wt.%训练范围，学生首次判断不能放心外推，正确，不作为错题。
