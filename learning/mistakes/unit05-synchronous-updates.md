# 单元05：同步更新时混用新旧参数

## 2026-10-17：闭卷复查记录

### 本次题目与回答

题目中的操作顺序：

1. 用整组旧参数计算偏导分量 g_0。
2. 立即更新 theta_0。
3. 用新 theta_0 和其他旧参数计算偏导分量 g_4。
4. 更新 theta_4。

学生对“这是否满足同步更新”的首次回答：

> 满足吧

本次判断不正确。前面的学习中已经讨论过整组旧参数的要求，学生也曾在讲解后正确说明混用新旧参数不在同一个旧参数位置。本轮更换情境后再次出现判断错误，说明这一概念尚未稳定掌握；不能仅根据此前补答认定已掌握。

### 需要区分的规则

- 同步更新要求：这一轮所有偏导分量，都在同一整组旧参数的位置计算。
- 不能只看某个参数本身是否还未更新；其他参数的更新也可能改变该偏导的计算位置。
- 如果全部偏导已经使用同一整组旧参数计算并保存，之后逐条赋值并不违反同步更新。
- 先更新部分参数，再使用混合的新旧参数计算后续偏导，不是本单元要求的同步更新。
