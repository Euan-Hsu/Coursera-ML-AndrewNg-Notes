## 2. 两个特征、三个样本：手算预测

教师给定Zn、Mg两个输入：

| 样本 | Zn | Mg |
|---|---|---|
| 1 | 7 | 2 |
| 2 | 8 | 1 |
| 3 | 6 | 3 |

参数为截距100、Zn参数40、Mg参数20。

学生作答：

- 原始矩阵shape为 `(3,2)`，增广矩阵为 `(3,3)`。
- 参数列数组为 `(3,1)`，批量预测为 `(3,1)`。
- 样本1：`100 + 280 + 40 = 420`。
- 样本2：`100 + 320 + 20 = 440`。
- 样本3：`100 + 240 + 60 = 400`。
- 常数列用于表示截距，不是新的材料特征，所以 `n=2`。

这些是学生实际完成的手算和shape判断，不是运行输出。

## 3. 数组构造：原始思路、标点错误与修订

学生最初提交的代码如下，保留全角逗号错误：

```python
import numpy as np

X = np.array([
    [1, 7，2],
    [1, 8，1],
    [1, 6，3]
])
theta = np.array([[100], [40], [20]])
print(X.shape)
print(theta.shape)
```

代码审查发现：`，` 不是Python数组元素的合法分隔逗号。教师提示后，学生将三行改为 `[1,7,2]`、`[1,8,1]`、`[1,6,3]`，并正确给出 `X.shape=(3,3)`、`theta.shape=(3,1)`。这是对原程序的片段修订，没有证据表明学生提交过运行日志。

之后在四样本版本补写预测语句时，学生最初写：

```text
y_hat = 100 + 40 * x_1 + 20 * x_2
```

这个展开式表达了模型关系，但该程序没有定义 `x_1`、`x_2`。本题要求使用已经定义的矩阵进行批量预测。

经“特征矩阵放左边、参数向量放右边、中间使用矩阵乘法”的提示，学生修订为：

```python
y_hat = X @ theta
```

随后能判断 `(4,3) @ (3,1) -> (4,1)`，以及反向 `(3,1) @ (4,3)` 因内侧维度不等而不合法；第4个样本 `[1,9,2]` 的手算预测是500。单行内各项与同一组参数对应相乘，再相加。

## 4. NumPy索引：初答错误与不同尺寸复测

闭卷第6题由教师给定一个 `(6,4)` 的增广数组A，列为常数、Zn、Mg、Cu。

学生能正确识别 `m=6,n=3`、取出的数值及材料变量，但首次把：

- `A[4, :]` 的shape写为 `(1,4)`。
- `A[:, 2]` 的shape写为 `(6,1)`。

教师解释：这里单个整数索引固定并去掉一个轴，冒号保留另一轴。上述返回数组是一维，而不是仍保留二维行列方向。

随后教师用新数组复测：

```python
B = np.array([[1, 2], [1, 4], [1, 6], [1, 8], [1, 10]])
```

学生正确回答：

| 表达式 | 返回值 | shape | 轴数 |
|---|---|---|---|
| `B[3, :]` | `[1,8]` | `(2,)` | 1 |
| `B[:, 1]` | `[2,4,6,8,10]` | `(5,)` | 1 |

这是纠正后的即时迁移复测通过，不是原题首次全对。

## 5. 闭卷第7题：自己构造参数并预测

教师给定五个样本的增广矩阵、模拟目标值和参数顺序“截距、特征1参数、特征2参数”，参数为20、2、-1。

学生独立补全 `theta = np.array([[20], [2], [-1]])` 和 `y_hat = X @ theta`，并正确判断：

- `theta.shape=(3,1)`、`y_hat.shape=(5,1)`。
- `y[1, :]` 返回 `[27]`，shape为 `(1,)`。
- `y_hat[1, :]` 返回 `[26]`，shape为 `(1,)`。

学生把 `y[1, :]` 描述为“第二个样本的模拟数据”。教师细化为“第二个样本的目标值”：模拟说明来源，目标值说明作用；`y_hat` 则是预测值。

### 归档拼接版代码：不是原始整段提交，也不是运行日志

下面只将已做过的第7题拼成完整示例，未添加新的已完成练习。`X`、`y` 和参数数值由教师给定；`theta` 的数组构造和 `y_hat` 语句由学生独立补写；导入语句、拼接和打印由归档整理添加。

```python
import numpy as np

# 全部数值为 synthetic data，不是实验结果。
# X、y由教师给定；X已经包含常数列。
X = np.array([
    [1, 1, 2],
    [1, 3, 0],
    [1, 2, 1],
    [1, 4, 3],
    [1, 0, 5]
])
y = np.array([[19], [27], [23], [26], [16]])

# 以下数组构造和预测语句由学生独立补写。
theta = np.array([
    [20],
    [2],
    [-1]
])
y_hat = X @ theta

# 以下打印由归档整理添加，供之后自行运行检查。
print(theta.shape)
print(y_hat.shape)
print(y[1, :], y[1, :].shape)
print(y_hat[1, :], y_hat[1, :].shape)
```

核对依据是学生纸面答案：参数shape为 `(3,1)`、预测shape为 `(5,1)`，第2个目标与预测分别为27与26，取行返回shape均为 `(1,)`。本次补档未新增学生或助手的Python运行证据。

## 6. 最终材料索引迁移

在11样本、输入顺序为Zn、Mg、Cu、ZrB2、时效温度、时效时间、目标只有UTS的结构题中，学生全部答对：

- 原始矩阵 `(11,6)`、增广矩阵 `(11,7)`。
- 参数 `(7,1)`、目标和预测 `(11,1)`。
- `X[:, 4]` 是所有样本的ZrB2含量，返回shape为 `(11,)`。
- `X[8, 5]` 是第9个样本的时效温度，是标量。
- `theta_4` 是ZrB2对应的参数，不是材料含量本身，同一个模型的全部样本共享它。

该题为synthetic data的结构设定，不声称已有相应实验数据。
