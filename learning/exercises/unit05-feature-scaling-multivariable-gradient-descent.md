## 1. 手算标准化，并比较缩放前后

### 1.1 时效温度与 ZrB₂ 含量

三条模拟样本的两列输入为：

| 样本 | 时效温度 / °C | ZrB₂ / wt.% |
|---|---:|---:|
| 1 | 120 | 0.5 |
| 2 | 150 | 1.0 |
| 3 | 180 | 1.5 |

本单元采用的 mean normalization 为 `(x - mean) / (max - min)`：温度均值为150、极差为60；ZrB₂均值为1、极差为1。两列都变为 `[-0.5, 0, 0.5]`。

z-score 采用总体标准差，与 `np.std(..., ddof=0)` 一致：

| 特征 | 均值 | 标准差 | z-score 结果（约值） |
|---|---:|---:|---|
| 时效温度 | 150 | 24.49 | `[-1.22, 0, 1.22]` |
| ZrB₂含量 | 1.00 | 0.4082 | `[-1.22, 0, 1.22]` |

学生实际手算：`(120 - 150) / 24.49 = -1.22`，计算正确。对标准化后为0的理解，先表述为“归一化后为0，实际为150”，随后补充为“样本时效温度等于平均时效温度”。

学生比较后指出尺度接近、真实数值未变。需保留的边界：此例两列恰好得到相同数列，不代表所有特征经 z-score 后具有相同取值范围或分布；标准差都为1也不代表预测重要性相同。

### 1.2 标准化不是直接替换输入而保持原系数

固定其他输入后，模拟模型为 `y_hat = 200 + 2T`。取 `T = 150 °C`，预测为500 MPa。

学生算出：直接把标准化后的 `z = 0` 代入同一数值系数，会得到200 MPa，因此不能保持原系数不变。讲解后的等价表示为：

`T = 150 + 24.49z`

`y_hat = 500 + 48.98z`

这里保留的是同一个预测关系；系数改变是为了匹配新的输入表示，不能仅凭系数数值增大认定特征更重要。

### 1.3 后续手算与独立复查

| 练习 | 学生结果 | 评价 |
|---|---|---|
| Zn训练均值7.5 wt.%、标准差0.5 wt.%，样本8.5 wt.% | `(8.5 - 7.5) / 0.5 = 2` | 数值独立正确；“高于训练均值2个标准差”的完整解释经提示补全。 |
| ZrB₂训练均值0.75 wt.%、标准差0.25 wt.%，新样本1.25 wt.%；新批次统计量不同 | `(1.25 - 0.75) / 0.25 = 2`，选择训练数据统计量 | 经此前讲解后的独立迁移复查正确；不是首次接触该规则。 |

## 2. 六特征模型的一次梯度下降手算

### 2.1 两个样本，代价从200降至98

两个模拟样本已经完成输入标准化：

| 样本 | Zn | Mg | Cu | ZrB₂ | 温度 | 时间 | UTS / MPa |
|---|---:|---:|---:|---:|---:|---:|---:|
| 1 | -1 | -1 | -1 | -1 | -1 | 1 | 480 |
| 2 | 1 | 1 | 1 | 1 | 1 | -1 | 520 |

初始参数为 `theta_0 = 500`、其余六个系数为0，学习率 `alpha = 0.05`。使用：

`J = sum((y_hat - y)**2) / (2*m)`，其中 `m = 2`。

学生分步计算与修正：

1. 初始预测均为500，误差为20、-20，计算正确。
2. `g_4 = -20`，更新后 `theta_4 = 1`，计算正确。
3. `g_0 = 0`、`g_6 = 20`；更新后 `theta_0 = 500`、`theta_6 = -1`，计算正确。
4. 此例前五个输入列完全相同，因此 `g_1` 至 `g_5` 均为-20，更新后的系数均为1。它们都是在同一整组旧参数处计算的。
5. 更新后两条预测为494、506，学生计算正确；误差为14、-14。
6. 学生最初把代价算成16.33，混淆了样本数与特征数。提示分母使用 `2*m` 后，修正为 `(196 + 196) / 4 = 98`。初始代价为 `(400 + 400) / 4 = 200`。

这是特意简化的手算数据：列之间存在完全相关，不能据此讨论六个材料变量的独立作用或真实因果关系。

### 2.2 第5题：偏导数符号的调试

模拟条件：两个样本的 `z_4 = [-1, 1]`，模拟目标UTS为 `[490, 510]`；旧 `theta_0 = 500`、`theta_4 = 2`，其他系数为0，`alpha = 0.1`。

学生首次回答为 `g_4 = 8`、新 `theta_4 = 1.2`。更新公式结构正确，偏导数结果错误。

提示使用“每个样本误差乘以对应输入，再取平均”后，学生逐项给出：

| 样本 | 预测 | 误差 `e = y_hat - y` | `e * z_4` |
|---|---:|---:|---:|
| 1 | 498 | 8 | -8 |
| 2 | 502 | -8 | -8 |

随后学生正确算出：`g_4 = (-8 - 8) / 2 = -8`；新 `theta_4 = 2 - 0.1*(-8) = 2.8`，参数增大。本题为提示后纠正，不能记为首次独立答对；仅凭首次结果也不能确定学生当时具体漏了哪一步。

### 2.3 第16题：独立复查偏导与参数变化量

给定模拟样本的 `z_4 = [-1, 1]`、旧参数处的误差为 `[6, -2]`，旧 `theta_4 = 1.2`、`alpha = 0.05`。

学生独立给出的结果为：

- `g_4 = -4`。
- 参数变化量数值为0.2，新参数为1.4。
- `g_4` 是完整梯度中的一个分量。

教师归档核对：`g_4 = (6*(-1) + (-2)*1) / 2 = -4`。这个加权平均展开式不是学生当时原样写出的计算过程。

学生把第二项写作 `Δg_4 = 0.2`，教师更正为 `Δtheta_4 = -alpha*g_4 = 0.2`。数值计算通过，但符号更正不能省略：本题没有计算梯度分量本身的变化量。

## 3. NumPy：从错误尝试到完整流程

### 3.1 典型原始尝试与问题

| 原始尝试 | 实际问题 | 教学处理及结果 |
|---|---|---|
| `print(mu)` 或打印原始矩阵的均值、标准差，作为标准化结果检查 | 计算统计量、显示已有变量、检查标准化结果是不同任务。 | 分开练习“计算并保存”与“检查”；后续能独立检查标准化矩阵。 |
| 用 `axis=1` 求每列的统计量 | 把样本维度与特征维度混淆。 | 用“第1列的多个样本值”具体说明；后续多次分项复查能选 `axis=0`。 |
| `X_scaled = (x - mu) / sigma` | `x` 未定义，且不是题目给定的完整原始输入矩阵。 | 提示后又出现以输出变量作输入，教师提供过完整最小版本；不能把该次记为独立完成。 |
| `X_scaled = (X_scaled - mu) / sigma` | 对待生成结果或已有结果重复套用原始数据的统计量。 | 澄清原始输入、转换统计量、标准化输出三个角色。 |
| 把标准化后的矩阵形状写为 `(6,)` | 把逐元素转换与按列汇总混为一谈。 | 比较两个Zn样本 `[7, 8]` 标准化后仍有两个值；随后 `(8, 6)` 的形状迁移判断正确。 |
| `Shape.mu = (6,)`、`Mu.Shape = (6,)` | 如果意图是执行形状查询，这不是正确写法，变量名与属性大小写也不一致；如果只是用文字报告形状，则应另行评价括号内数值，不能仅凭排版认定其意图。 | 教师说明查询写法是 `mu.shape` 或 `print(mu.shape)`；不能将教师给出的查询代码记为学生独立提交。 |

### 3.2 第12题：七样本矩阵的调试证据

题设 `R_raw.shape = (7, 6)`，每列标准差非零。学生首次提交的关键内容为：

```python
mu = np.mean(R_raw, axis=0)
Sigma = np.std(R_raw, axis=0)
R_caled = (R_raw - mu) / sigma
Shape.mu = (6,)
Shape.sigma = (6,)
Shape.M_scaled = (7, 6)
```

统计函数和列方向正确，但存在 `Sigma/sigma` 大小写不一致、`R_caled` 与指定结果名 `R_scaled` 不一致、残留其他题目的 `M_scaled` 名称，以及未提交两行结果检查。`R_caled` 本身是合法的Python变量名，问题是它与题目指定名称及后续引用不一致，而不是该名字语法非法。

教师使用七行六列模拟测试输入，在干净的Python进程中核验前三行，首个报错为 `NameError: name 'sigma' is not defined`。这说明不能用旧环境里可能残留的同名变量掩盖本次代码的不完整。

为便于复现，教师当时使用的输入夹具记录如下。它是教师提供的 **synthetic data（模拟数据）**，不是学生生成的数据，也不是学生提交的代码；这里仅归档已有测试输入，没有重新运行：


提示后学生提交了正确的五行计算与检查代码，按[测验档Q12](../quizzes/unit05-feature-scaling-multivariable-gradient-descent.md)中已留存的语义转录补齐如下；这不是新增作答：
