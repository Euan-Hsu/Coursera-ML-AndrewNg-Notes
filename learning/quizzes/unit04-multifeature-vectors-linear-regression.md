## 概念题（3题）

### 第1题：样本、特征与数学符号

**题目**：有8个材料样本，每个样本的特征依次是Zn、Mg、Cu含量。判断m、n，解释 x^(5) 和 x_2^(5)，并给出单样本向量的shape及单个值的类型。

**学生作答摘要**：

- m = 8，n = 3。
- x^(5) 是第5个样本的所有特征，shape为(3, 1)。
- x_2^(5) 是第5个样本的Mg含量，是标量。

**结果**：正确。

### 第2题：参数数量与样本数量

**题目**：12个样本、4个材料特征，模型含截距。有人认为每个样本对应一个参数，所以theta.shape应为(12, 1)。判断该说法，写出正确shape，并说明样本数增加到20时参数数量是否改变。

**首次作答摘要**：不同意；每个特征对应一个参数，还要加截距；样本增加时参数数量不变。首次回答漏写具体theta.shape。

**补答摘要**：theta.shape = (5, 1)；参数数量与特征数量和截距有关，与样本数无关。

**结果**：逻辑正确，补写缺失shape后通过。不是首次给出了完整答案。

### 第3题：目标、预测与一维数组

**题目**：真实材料研究中预测7个样本的UTS。解释y、y_hat；按二维列数组约定给出它们的shape；判断shape为(7,)的NumPy数组是否可以称为7行1列。

**学生作答摘要**：

- y是材料真实值，y_hat是模型预测值。
- y.shape = (7, 1)，y_hat.shape = (7, 1)。
- (7,)是一维，不能称为二维的7行1列。

**教师措辞细化**：这里的y具体是每个样本的UTS目标值，不是所有材料数据。

**结果**：判断正确。

## 数学理解题（2题）

### 第4题：乘法合法不等于含截距表示正确

**题目**：9个样本、5个材料特征，要求模型含截距。某同学使用X_raw.shape = (9, 5)、theta.shape = (5, 1)，认为内侧维度匹配就已经正确表示含截距的模型。判断乘法是否合法、输出shape和模型表示是否满足要求，再写出增广表示的shape。

**学生作答摘要**：

- 可以计算，输出shape为(9, 1)。
- 尚未正确表示要求的含截距模型；5个材料特征加截距需要6个参数。
- 增广X.shape = (9, 6)，theta.shape = (6, 1)。

**结果**：正确。

### 第5题：手算与所有样本的预测

**题目数据：synthetic data。** X已包含常数列：

```text
X = [[1, 2, 1],
     [1, 0, 3],
     [1, 4, 2],
     [1, 1, 0],
     [1, 3, 1]]
theta = [[10], [2], [-1]]
```

要求判断m、n；手算第3个样本；给出X、theta和X @ theta的shape；解释为什么每个样本得到一个预测值。

**首次作答摘要**：

- m = 5，n = 2。
- 第3个样本：10 + 4 * 2 + 2 * (-1) = 16。
- X.shape = (5, 3)，theta.shape = (3, 1)，(X @ theta).shape = (5, 1)。
- 输出解释依据shape，但把输出最后一维的来源表述为“特征的最后一个数字”，未明确说明每行的计算机制。

**教师补充与追问**：输出的1来自theta的列数；theta是参数，不是特征数据。要求不用shape解释每行怎样得到预测值，以及不同样本是否共享参数。

**学生补答摘要**：X一行中的各项与theta对应项相乘再相加；每个样本使用同一组theta。

**结果**：数值与shape首次正确，机制说明经追问补充后通过。

### 数学推导与结果解释补充（教师归纳，非新增测验）

单个样本的增广行与参数列相乘，就是把对应项乘积求和：

\[
\hat y^{(i)}
=
\begin{bmatrix}1 & x_1^{(i)} & \cdots & x_n^{(i)}\end{bmatrix}
\begin{bmatrix}
\theta_0\\
\theta_1\\
\vdots\\
\theta_n
\end{bmatrix}
=
\theta_0+\sum_{j=1}^{n}\theta_j x_j^{(i)}
\]

每一行得到一个预测值；把m行放在一起就是增广X乘theta，输出shape为(m, 1)。这解释了第3个样本为何得到16，以及所有样本为何共享参数而各有预测值。

本段仅把本单元已讲过的对应相乘、相加整理成公式，不把它记作学生另行独立完成的一道推导题，不涉及矩阵求导。

## Python题（2题）

### 第6题：整数索引取行、取列

**题目数据：synthetic data。** A的列依次为常数1、Zn、Mg、Cu：

```python
A = np.array([
    [1, 2, 7, 4],
    [1, 3, 8, 5],
    [1, 4, 9, 6],
    [1, 5, 10, 7],
    [1, 6, 11, 8],
    [1, 7, 12, 9]
])
```

要求判断A.shape、m、n，以及A[4, :]和A[:, 2]的值、材料含义与返回shape。

**首次作答摘要**：

- A.shape = (6, 4)，m = 6，n = 3：正确。
- A[4, :]为第5个样本，值为[1, 6, 11, 8]：正确；返回shape写为(1, 4)：错误。
- A[:, 2]对应Mg，数值7至12取对；将返回值写成多个列元素，shape写为(6, 1)：错误。

**教师纠正，不是学生首次答案**：对于这里的二维数组，单个整数索引去掉一个轴，冒号保留另一个轴。A[4, :]的shape为(4,)；A[:, 2]的一维值为[7, 8, 9, 10, 11, 12]，shape为(6,)。

**纠错后的不同尺寸复测数据：synthetic data。**

```python
B = np.array([
    [1, 2],
    [1, 4],
    [1, 6],
    [1, 8],
    [1, 10]
])
```

**学生复测答案**：

- B[3, :]返回[1, 8]，shape为(2,)，一个轴。
- B[:, 1]返回[2, 4, 6, 8, 10]，shape为(5,)，一个轴。

**结果**：首次答错；纠正后即时迁移复测通过。需继续保留NumPy索引降维这一薄弱点。

### 第7题：np.array、参数列数组与X @ theta

**题目数据：synthetic data。** X包含常数列，y是模拟目标值。要求使用np.array构造参数20、2、-1的二维列数组，计算预测，判断theta、y_hat及第2个样本取行结果的值和shape。

```python
X = np.array([
    [1, 1, 2],
    [1, 3, 0],
    [1, 2, 1],
    [1, 4, 3],
    [1, 0, 5]
])
y = np.array([[19], [27], [23], [26], [16]])
```

**学生独立补写的代码**：

```python
theta = np.array([
    [20],
    [2],
    [-1]
])
y_hat = X @ theta
```

**学生判断摘要**：

- theta.shape = (3, 1)，y_hat.shape = (5, 1)。
- y[1, :]返回[27]，shape为(1,)，描述为第2个样本的模拟数据。
- y_hat[1, :]返回[26]，shape为(1,)，是第2个样本的模型预测值。

**教师措辞细化**：y[1, :]是第2个样本的目标值，本例用synthetic data提供。“模拟数据”是来源，“目标值”是作用。

**结果**：代码、数值与shape正确；目标含义的文字表述经教师细化。记录仅依据对话中的代码与作答，不声称学生提交了实际运行日志。

## 材料科学迁移题（1题）

### 第8题：六特征7085Al基复合材料案例

**题目**：synthetic data的结构设定，不代表已有实验结果。11个材料样本，输入依次为Zn、Mg、Cu、ZrB2、时效温度、时效时间，目标只有UTS；模型含截距。X_raw为原始矩阵，X为最左侧增加常数列后的增广矩阵，theta、y使用二维列数组。

要求判断m、n和各shape，解释X[:, 4]、X[8, 5]和theta_4。

**学生独立作答摘要**：

- m = 11，n = 6。
- X_raw.shape = (11, 6)，X.shape = (11, 7)。
- theta.shape = (7, 1)，y.shape = (11, 1)，(X @ theta).shape = (11, 1)。
- X[:, 4]包含所有样本的ZrB2含量，NumPy返回shape为(11,)。
- X[8, 5]是第9个样本的时效温度，是标量。
- theta_4对应ZrB2含量，是模型参数而不是材料含量；同一模型的全部样本共享这个参数。

**结果**：全部正确；列索引和一维返回规则能够迁移到新的材料数据尺寸。
