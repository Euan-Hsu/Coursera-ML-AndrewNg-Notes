## 概念题1：监督来自哪里

题目：监督学习是否必须有人在旁边实时观察模型学习？“监督”实际上来自哪里？

学生答案：“不是，监督来自数据同时给出输入与已知正确结果”。

评价：首次独立作答正确。监督来自输入与对应目标的配对。

## 概念题2：完整训练样本

题目：为什么只有“ZrB₂含量为0.5 wt.%”不能构成当前任务中的完整监督训练样本？需要补充什么？

学生答案：“训练样本应同时包括ZrB₂含量与UTS的配对”。

评价：正确。教师明确补充该条件下对应的已知目标UTS。

## 概念题3：单变量与样本数

题目：100个训练样本、每个样本只使用ZrB₂含量预测UTS，仍是单变量线性回归吗？“单变量”指一个样本还是一个feature？

学生答案：“是线性回归，单变量指1个feature”。

评价：单变量的判断正确。教师补充必须采用线性模型；仅有一个feature不能单独保证模型是线性回归。

## 数学理解题1：预测与参数

题目模型：

~~~text
y_hat = 500 + 40 * x
x = 0.75
~~~

x以wt.%数值编码，y_hat单位为MPa。要求计算预测并指出两个参数。

学生答案：“预测值=530，theta_0和theta_1分别为500和40”。

评价：首次独立作答正确。教师补充预测单位MPa、斜率单位MPa/(wt.%)。

## 数学理解题2：预测变化量

题目：同一模型中，x从0.25 wt.%增加到0.85 wt.%，预测UTS改变多少？

学生答案：“24”。

评价：首次独立作答正确；教师补全单位MPa和计算过程。题干已经提示先计算含量变化再乘斜率，因此不记作完全无提示推导。

## Python题1：预测表达式

题目给定：

~~~python
theta_0 = 500
theta_1 = 40
x = 0.75
~~~

要求补写一行代码，将预测值保存到y_hat。

学生代码：

~~~python
y_hat = theta_0 + theta_1 * x
~~~

评价：首次独立编写正确。学生原消息的代码围栏标为ini，教师只修正显示标签。

## Python题2：预测函数

题目：

~~~python
def predict_uts(x, theta_0, theta_1):
    # 补写函数体
~~~

学生首次作答，以下规范化聊天中的转义和缩进显示：

~~~python
def predict_uts(x, theta_0, theta_1):
    predict_uts = theta_0 + theta_1 * x
~~~

评价：缺少return，未独立完成所要求的返回逻辑。同名局部赋值不是Python语法错误。

反馈过程：教师先说明问题并给出return提示；学生回答“我不会写代码”；教师随后提供完整函数并逐行解释。

教师示例：

~~~python
def predict_uts(x, theta_0, theta_1):
    return theta_0 + theta_1 * x

result = predict_uts(0.75, 500, 40)
~~~

随后问result的数值，学生回答：“530”。

最终状态：读懂教师示例后的数值判断正确；不能记为独立实现函数，也没有实际运行验证。

## 材料迁移题：相关关系与因果

题目：ZrB₂含量与时效温度同时升高，UTS总体上升。只用ZrB₂含量的单变量线性回归得到正斜率，是否能断定UTS提高一定由ZrB₂增加造成？为什么？

学生答案：“不能吧，时效温度也是变量之一”。

评价：首次独立作答正确，意识到时效温度是共同变化的影响因素。教师进一步解释混杂因素与相关性，不能把教师解释全部记为学生原答。
