## 1. 概念理解：预测函数

题目：h_theta(x)是什么？接收什么、输出什么、theta下标表示什么？

学生答：“接受输入模型的feature x,输出prediction y_hat,下标决定函数的形状位置，theta_0决定x=0的大小，theta_1决定x改变1单位，y_hat的变化量”。

评价：首次作答通过。教师补充下标表示函数由模型参数控制。

## 2. 数学符号：预测、误差与参数共享

3. 在x^(i)、y^(i)、y_hat^(i)、theta_0、theta_1中指出样本量与共享参数。

第一条消息未发完整，教师请其继续，未按错误计分。

学生完整答：“y_hat = theta_o + theta_1 * x; e = y_hat - y; y_hat和e随样本变化,theta_0和theta_1是共用参数”。

## 4. 代价函数：公式、数值与正负抵消

题目：三个样本误差为[-3, 1, 5] MPa。写J公式、算J、解释为什么不能直接加有符号误差。

学生首次答：“1、J = SUM(e^2)/2m；2、7/3”。

评价：教师按此前明确的分母2m理解公式，结构正确；数值错误；第三问未答。

教师提示：逐个算平方、平方和和2m。

学生更正：“2、35/6; 3、不能，正负号会让误差抵消”。

评价：提示后正确，不记作首次独立全对。为验证计算，后来安排新题复测，见第7节。

## 5. Python理解：数组与返回值

教师给出：

~~~python
def compute_cost(x, y, theta_0, theta_1):
    m = len(x)
    y_hat = theta_0 + theta_1 * x
    errors = y_hat - y
    squared_errors = errors ** 2
    return squared_errors.sum() / (2 * m)
~~~

问题：为何x、y用数组？errors ** 2做什么？返回逐样本误差还是整体cost？

学生答：“1、因为数组能进行数学运算；2、对误差进行了平方；3、返回的是cost数值”。

评价：基本通过。第一项笼统，教师补充数组保存全部配对样本并逐项运算。没有独立程序编写或运行证据。

本单元教学阶段还完成两项Python阅读/手算任务：批量预测[500,520,540]首次正确；误差[-2,2,-1]和平方[4,4,1]经提示补全，cost = 1.5正确。详见练习档案，不额外编造成两项独立编程测验。

## 6. 材料迁移：斜率、因果与外推

题目：模型y_hat = 505 + 35x，训练J小；ZrB₂含量高的样本时效温度也高，训练范围0—1 wt.%。

问：斜率含义、是否证明因果、能否放心预测3 wt.%、小训练J说明什么？

学生首次答：

1. “表示ZrB₂含量x每改变1wt.%，UTS的变化量”。
2. “能，因为theta_1为正”。
3. “不能因为训练集含量范围仅0–1 wt.%”。
4. “说明模型在该数据集下预测效果较好”。

评价：第3项正确。第1项应限定预测UTS；第2项把正相关当因果；第4项应明确当前训练拟合。

教师说明混杂因素后，学生更正：

1. x每改变一个单位，y_hat即预测UTS变化。
2. “只能说明模型正相关，还可能受到其他因素影响”。
3. “说明对当前数据拟合较好”。

此轮是反馈后修订；后来再安排材料情境复测。

## 7. 独立复测：代价函数

新题误差[-4, 2, 6]，要求写平方和、2m、J；题干仍给出J公式，因此为新数值计算复测，不是无提示背写公式。

新题：y_hat = 510 + 30x、训练J小；高ZrB₂含量样本时效时间也更长。问能得出和不能得出的结论。

评价：修正后正确。此项最终通过包含提示和纠错，不记为独立新题首次正确；其后没有新的无提示复测。
